# IT 服务指南

## VPN 使用

公司 VPN 用于外网访问内部系统。

连接步骤：下载并安装最新版 VPN 客户端（低于 3.2 版本无法连接）；使用域账号登录；选择「办公网」节点。

连接失败时，先检查客户端版本，再检查网络是否可访问 vpn.example.com 的 443 端口。

连接后无法访问内部系统，检查是否选择了「办公网」节点而非「研发网」。

## 账号与密码

域账号密码每 90 天需修改一次，且不能与前 3 次重复。

连续输错 5 次密码，账号将被锁定 30 分钟。解锁需联系 IT 服务台。

离职员工的账号在离职当日 18:00 自动禁用。

## 电脑与设备

新员工入职当天在 IT 服务台领取电脑。

开发岗：16GB 内存、512GB SSD、i7 处理器。

非开发岗：16GB 内存、256GB SSD。

设备故障在 IT 服务台提交工单，常规问题 1 个工作日内处理，需更换硬件的 3 个工作日内处理。

## 软件安装

正版软件由 IT 统一采购和分发。

开发工具可在软件中心「自服务」中申请，一般 2 小时内自动安装。

禁止安装未授权软件，包括破解版工具。

## 数据安全

公司数据分为「公开」「内部」「机密」三个等级。

「机密」级数据禁止通过个人邮箱、网盘、即时通讯工具外传。

对外发送文件需经过 DLP 系统审批，审批通过后文件有效期为 7 天。
