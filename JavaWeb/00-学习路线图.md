# Java Web 学习路线图

> 本文档是整个 Java Web 学习笔记的**总导航**，按由浅入深的顺序组织全部知识点文档。
> 前置基础：已学完 [Java SE 学习路线图](../Java基础/00-学习路线图.md)（至少到集合、IO、异常、网络编程）；建议先了解 [Maven 使用文档](../Spring/Maven%20使用文档.md)——现代 JavaWeb 工程用 Maven 管理依赖，Spring Boot 更是完全基于 Maven/Gradle。
> 学习定位：**面向实际开发，为 Spring Boot 打基础**。原生 Servlet/JSP 现代项目已很少直接手写，但它们是 Spring MVC / Spring Boot 的底层实现原理——理解得越深，用 Spring Boot 时越知道它在帮你省什么、出了问题才知道往哪查。
> 阅读建议：按编号顺序学习，每篇配合代码动手敲一遍；带 ⭐ 的是开发高频/面试重点，务必吃透。

---

## 这份路线图的设计理念

在开始列知识点之前，先说清楚"为什么这么排"：

1. **原生 Web 是"原理课"，不是"生产工具课"**。现代 Java 后端 99% 用 Spring Boot，几乎没人再手写 Servlet + JSP 上线项目。但 Spring Boot 的 DispatcherServlet、`@RequestMapping`、`@RequestBody`、Filter 链、Session 管理全部建立在 Servlet 规范之上。**学 JavaWeb 的目的，是让你将来用 Spring Boot 时"知其然也知其所以然"**。
2. **砍掉过时内容，保留原理内核**。传统教程里大量篇幅的 JSP 自定义标签库、EL 函数、JSTL 格式化标签等，在前后端分离时代已无生产价值，本路线图**只保留 JSP 原理与 MVC 思想**（因为它是 Spring MVC 视图解析的前身），不深钻 JSP 细节。
3. **数据库提前穿插**。Web 后端没有数据就是空中楼阁，所以 MySQL + JDBC + 连接池放在中段，而不是最后。
4. **每个知识点都标注"在 Spring Boot 中对应什么"**。让你学每一篇时都知道：这个底层概念，将来被 Spring Boot 的哪个特性封装了。

## 阶段一：Web 基础与环境

- [01-Tomcat 与 Web 服务器](01-Tomcat%20与%20Web%20服务器.md) ⭐
  - B/S 与 C/S 架构；Web 服务器概念；Tomcat 安装/启动/目录结构；**虚拟目录与三种部署方式**；IDEA 集成 Tomcat
  - 📌 Spring Boot 对应：**内嵌 Tomcat**，无需单独安装，`server.port` 改端口
- [02-Servlet 入门](02-Servlet%20入门.md) ⭐
  - Servlet 体系与生命周期（init/service/destroy）；**Servlet 接口实现链**；url-pattern 匹配规则；Servlet 3.0 注解配置 `@WebServlet`
  - 📌 Spring Boot 对应：Spring MVC 的 `DispatcherServlet` **本身就是一个 Servlet**，`@RestController` 的方法由它分发调用；注解配置取代了 `@WebServlet`
- [03-HTTP 协议](03-HTTP%20协议.md) ⭐
  - 请求/响应报文结构；**7 种请求方法**与幂等性；常见状态码；请求头/响应头；GET 与 POST 本质区别
  - 📌 Spring Boot 对应：`@GetMapping`/`@PostMapping`、`@RequestHeader`、`ResponseEntity` 状态码

## 阶段二：Servlet 核心机制

- [04-Request 请求对象](04-Request%20请求对象.md) ⭐
  - 获取请求行/头/参数；**GET 与 POST 乱码解决**；请求转发与 `RequestDispatcher`；request 域对象
  - 📌 Spring Boot 对应：`@RequestParam`、`@RequestBody`、`@RequestHeader`、`HttpServletRequest` 注入
- [05-Response 响应对象](05-Response%20响应对象.md) ⭐
  - 设置响应行/头/体；**响应字符/字节流与中文乱码**；重定向与转发的区别；文件下载雏形
  - 📌 Spring Boot 对应：`@ResponseBody`、`ResponseEntity`、`RedirectView`

## 阶段三：会话管理

- [06-Cookie](06-Cookie.md)
  - Cookie 创建与发送；**会话级与持久级 Cookie**；编码与路径；Cookie 的局限与安全
  - 📌 Spring Boot 对应：`@CookieValue`、Spring Session 的 Cookie 序列化策略
- [07-Session](07-Session.md) ⭐
  - Session 创建与原理（JSESSIONID）；**Session 销毁与超时**；URL 重写；Cookie 与 Session 对比与选型
  - 📌 Spring Boot 对应：**Spring Session + Redis** 解决分布式会话，`spring.session.timeout`

## 阶段四：三大组件与域对象

- [08-Filter 过滤器](08-Filter%20过滤器.md) ⭐
  - Filter 接口与生命周期；**过滤器链与执行顺序**；`@WebFilter` 注解；统一编码/登录权限/敏感词过滤实战
  - 📌 Spring Boot 对应：`FilterRegistrationBean` 注册、Spring Security 的过滤链本质就是 Filter 链
- [09-Listener 监听器](09-Listener%20监听器.md)
  - 八大监听器（域对象/属性/Session 相关）；`@WebListener`；监听器在在线人数统计、启动初始化中的应用
  - 📌 Spring Boot 对应：`@EventListener`、`ApplicationListener`、`CommandLineRunner` 启动钩子
- [10-ServletContext 与四大域对象](10-ServletContext%20与四大域对象.md) ⭐
  - ServletContext 全局域；**四大域对象（PageContext/Request/Session/Application）作用范围与生命周期**；资源加载与全局参数；**容器管理组件的思想雏形**
  - 📌 Spring Boot 对应：Spring 的 `ApplicationContext` 既是 **IoC 容器**，也承担了 ServletContext 的全局共享角色——理解"容器管对象"是 Spring 的入门钥匙

## 阶段五：视图层与 MVC

- [11-JSP 基础与原理](11-JSP%20基础与原理.md)
  - JSP 本质（编译为 Servlet）；九大内置对象与四大作用域；指令/脚本/动作；**JSP 与 Servlet 的关系**
  - 📌 Spring Boot 对应：Thymeleaf / FreeMarker 模板引擎，JSP 已不推荐但原理相通
- [12-EL 表达式与 JSTL](12-EL%20表达式与%20JSTL.md)
  - EL 取值与运算；**11 个隐式对象**；JSTL 核心 `<c:if>/<c:forEach>`；MVC 中替代脚本
  - 📌 Spring Boot 对应：Thymeleaf 的 `${}`/`th:each`，表达式思想一脉相承
- [13-MVC 设计模式](13-MVC%20设计模式.md) ⭐
  - JSP Model1 与 Model2；**MVC 在 JavaWeb 中的落地**（Servlet=Controller、JSP=View、JavaBean=Model）；分层架构雏形
  - 📌 Spring Boot 对应：**Spring MVC 就是 MVC 的工程化实现**，`@Controller`/`@Service`/`@Repository` 分层注解

## 阶段六：Web 进阶

- [14-AJAX 与 JSON](14-AJAX%20与%20JSON.md) ⭐

- [15-文件上传下载](15-文件上传下载.md)
  - `multipart/form-data`；**Servlet 3.0 `@MultipartConfig`**；commons-fileupload；下载响应头与断点续传雏形

  - 📌 Spring Boot 对应：`@Async`、`DeferredResult`、Spring WebSocket

## 学习建议

1. **先跑通再深究**：阶段一务必先把 Tomcat + IDEA + Servlet 跑通一个 HelloWorld，建立"请求 → Servlet → 响应"的直觉，再回头抠细节。
2. **抓住一条主线**：HTTP 请求 → 到达 Tomcat → 匹配 Servlet → Request 取参 → 业务处理 → Response 写回 → Session 保持状态。所有知识点都挂在这条主线上。
3. **JSP 适度即可**：现代开发已前后端分离，JSP/EL/JSTL 理解原理即可，不必深钻；但 **MVC 思想必须吃透**，它是 Spring MVC 的前身。
4. **数据库穿插学**：阶段五之后就开始学 MySQL + JDBC，不要等到最后；Web 后端没有数据就是空中楼阁。
5. **动手做项目**：阶段八的综合案例是检验学习成果的唯一标准，建议至少独立完成一个带分页 + 登录 + 增删改查的小系统。
6. **带着"Spring Boot 会怎么简化这一步"的视角学**：每学一个原生知识点，对照文末的 📌 标注，思考 Spring Boot 帮你封装了什么——这是本路线图区别于传统教程的核心。
7. **以 Servlet 3.x 为基准**：所有代码基于 Servlet 3.0+ 注解配置（`@WebServlet`/`@WebFilter`），不再依赖 `web.xml`；Servlet 4.0+ 特性以「补充说明」给出。
