# 综合案例：学生管理系统

> 本篇是 Java Web 学习路线图的**收官项目**，用原生技术栈（Servlet + JSP + JDBC + Druid + Filter + Listener + AJAX）完成一个完整的学生管理系统。**目的不是让你背代码，而是让你亲手体验"原生开发有多繁琐"**——做完你会强烈感受到配置繁琐、样板重复、事务手动管的痛点，这正是 Spring Boot 要解决的核心问题。带着这个"痛感"进入 Spring Boot 学习，你就知道 Spring Boot 的每个特性在帮你省什么。

> 💡 本篇建议**动手实现**，至少完成"登录 + 分页列表 + 增删改查"核心模块。不必追求完美，重点是走通"请求 → Filter → Servlet → Service → DAO → DB → JSP → 响应"的完整链路，体会分层架构。

## 二、核心代码实现

### 2.1 启动初始化（Listener，09/10 篇）

```java
@WebListener
public class StartupListener implements ServletContextListener {
    @Override
    public void contextInitialized(ServletContextEvent sce) {
        // 初始化 Druid 连接池，存进 ServletContext 全局共享
        DruidDataSource ds = new DruidDataSource();
        ds.setUrl("jdbc:mysql://localhost:3306/student_db?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8");
        ds.setUsername("root");
        ds.setPassword("123456");
        ds.setDriverClassName("com.mysql.cj.jdbc.Driver");
        ds.setInitialSize(5);
        ds.setMaxActive(20);
        ds.setFilters("stat,wall");   // 监控 + 防火墙
        sce.getServletContext().setAttribute("dataSource", ds);
        System.out.println("=== 学生管理系统启动，连接池初始化 ===");
    }

    @Override
    public void contextDestroyed(ServletContextEvent sce) {
        DruidDataSource ds = (DruidDataSource) sce.getServletContext().getAttribute("dataSource");
        if (ds != null) ds.close();
    }
}
```

> 💡 **这就是 10 篇讲的"容器管全局对象"**：连接池由 Listener 在启动时创建、存进 ServletContext、全局共享。**做完你会感受到"手动存取、手动强转"的繁琐**——Spring Boot 的 `@Bean` + `@Autowired` 自动化了这个过程。

### 2.2 编码 + 鉴权 Filter（08 篇）

```java
// 统一编码 Filter
@WebFilter("/*")
public class EncodingFilter implements Filter {
    @Override
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        req.setCharacterEncoding("utf-8");
        resp.setCharacterEncoding("utf-8");
        chain.doFilter(req, resp);   // 放行
    }
}

// 登录鉴权 Filter
@WebFilter("/student/*")
public class AuthFilter implements Filter {
    @Override
    public void doFilter(ServletRequest req, ServletResponse resp, FilterChain chain)
            throws IOException, ServletException {
        HttpServletRequest request = (HttpServletRequest) req;
        HttpServletResponse response = (HttpServletResponse) resp;

        HttpSession session = request.getSession(false);
        if (session == null || session.getAttribute("admin") == null) {
            // 未登录，跳登录页
            response.sendRedirect(request.getContextPath() + "/login");
            return;   // ★ 不调 chain.doFilter = 拦截
        }
        chain.doFilter(req, resp);   // 已登录，放行
    }
}
```

> 💡 **这就是 08 篇讲的 Filter 链**：编码 Filter 拦所有请求设 UTF-8，鉴权 Filter 拦 `/student/*` 判登录。**做完你会感受到"手写 Filter、手动管顺序"的繁琐**——Spring Boot 的 `FilterRegistrationBean` + Spring Security 自动化了鉴权。

### 2.3 登录模块（Session，07 篇）

```java
@WebServlet("/login")
public class LoginServlet extends HttpServlet {
    private AdminService adminService = new AdminService();

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        req.setCharacterEncoding("utf-8");
        String username = req.getParameter("username");
        String password = req.getParameter("password");

        resp.setContentType("application/json;charset=utf-8");
        Admin admin = adminService.login(username, password);
        if (admin != null) {
            // 登录成功：Session 存登录态
            HttpSession session = req.getSession();
            session.setAttribute("admin", admin);
            session.setMaxInactiveInterval(60 * 30);   // 30 分钟
            resp.getWriter().write("{\"success\":true}");
        } else {
            resp.getWriter().write("{\"success\":false,\"msg\":\"用户名或密码错误\"}");
        }
    }
}

@WebServlet("/logout")
public class LogoutServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        HttpSession session = req.getSession(false);
        if (session != null) session.invalidate();   // 销毁 Session
        resp.sendRedirect(req.getContextPath() + "/login");
    }
}
```

> 💡 **这就是 07 篇讲的 Session 登录**：`getSession` 存登录态、`invalidate` 注销。**做完你会感受到"手动判 Session、手写鉴权"的繁琐**——Spring Security 的 `formLogin`/`logout` 自动化了这套流程。

### 2.4 DAO 层（JDBC + DBUtils，17/18 篇）

```java
public class StudentDao {
    private final QueryRunner qr;

    public StudentDao(ServletContext ctx) {
        DataSource ds = (DataSource) ctx.getAttribute("dataSource");
        this.qr = new QueryRunner(ds);
    }

    // 分页查询
    public List<Student> findByPage(int page, int size, String keyword) throws SQLException {
        String sql = "SELECT * FROM student";
        if (keyword != null && !keyword.isEmpty()) {
            sql += " WHERE name LIKE ?";
            sql += " LIMIT ? OFFSET ?";
            return qr.query(sql, new BeanListHandler<>(Student.class),
                    "%" + keyword + "%", size, (page - 1) * size);
        }
        sql += " LIMIT ? OFFSET ?";
        return qr.query(sql, new BeanListHandler<>(Student.class),
                size, (page - 1) * size);
    }

    // 总数
    public long count(String keyword) throws SQLException {
        if (keyword != null && !keyword.isEmpty()) {
            return qr.query("SELECT COUNT(*) FROM student WHERE name LIKE ?",
                    new ScalarHandler<Long>(), "%" + keyword + "%");
        }
        return qr.query("SELECT COUNT(*) FROM student", new ScalarHandler<Long>());
    }

    public Student findById(int id) throws SQLException {
        return qr.query("SELECT * FROM student WHERE id=?",
                new BeanHandler<>(Student.class), id);
    }

    public int add(Student s) throws SQLException {
        return qr.update("INSERT INTO student(name,age,gender,phone,avatar) VALUES(?,?,?,?,?)",
                s.getName(), s.getAge(), s.getGender(), s.getPhone(), s.getAvatar());
    }

    public int update(Student s) throws SQLException {
        return qr.update("UPDATE student SET name=?,age=?,gender=?,phone=?,avatar=? WHERE id=?",
                s.getName(), s.getAge(), s.getGender(), s.getPhone(), s.getAvatar(), s.getId());
    }

    public int delete(int id) throws SQLException {
        return qr.update("DELETE FROM student WHERE id=?", id);
    }
}
```

> 💡 **这就是 18 篇的 DBUtils + 17 篇的连接池**：`QueryRunner` 简化 CRUD，连接池从 ServletContext 取。**做完你会感受到"手写 SQL、手动拼条件、手动分页"的繁琐**——MyBatis-Plus 的 `BaseMapper` + `Page` 连 SQL 和分页都自动化了。

### 2.5 Service 层（业务 + 事务，13 篇）

```java
public class StudentService {
    private final StudentDao dao;

    public StudentService(ServletContext ctx) {
        this.dao = new StudentDao(ctx);
    }

    public PageResult<Student> list(int page, int size, String keyword) throws SQLException {
        List<Student> students = dao.findByPage(page, size, keyword);
        long total = dao.count(keyword);
        return new PageResult<>(students, total, page, size);
    }

    public Student get(int id) throws SQLException { return dao.findById(id); }

    public void add(Student s) throws SQLException { dao.add(s); }
    public void update(Student s) throws SQLException { dao.update(s); }
    public void delete(int id) throws SQLException { dao.delete(id); }
}
```

> 💡 **这就是 13 篇的三层架构**：Service 调 DAO，封装业务。**做完你会感受到"手动 new DAO、手动传 ServletContext"的繁琐**——Spring 的 `@Service`/`@Autowired` 自动创建和注入，不用手动传依赖。

### 2.6 Controller 层（Servlet + AJAX，04/14 篇）

```java
@WebServlet("/student/*")
public class StudentServlet extends HttpServlet {
    private StudentService service;

    @Override
    public void init() {
        service = new StudentService(getServletContext());
    }

    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        resp.setContentType("application/json;charset=utf-8");
        String action = req.getPathInfo();   // /list, /detail, /delete

        try {
            switch (action) {
                case "/list":
                    int page = Integer.parseInt(req.getParameter("page"));
                    int size = Integer.parseInt(req.getParameter("size"));
                    String keyword = req.getParameter("keyword");
                    PageResult<Student> result = service.list(page, size, keyword);
                    resp.getWriter().write(toJson(result));   // 返回 JSON
                    break;
                case "/detail":
                    int id = Integer.parseInt(req.getParameter("id"));
                    Student s = service.get(id);
                    resp.getWriter().write(toJson(s));
                    break;
                case "/delete":
                    int deleteId = Integer.parseInt(req.getParameter("id"));
                    service.delete(deleteId);
                    resp.getWriter().write("{\"success\":true}");
                    break;
            }
        } catch (Exception e) {
            resp.getWriter().write("{\"success\":false,\"msg\":\"" + e.getMessage() + "\"}");
        }
    }

    @Override
    protected void doPost(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        req.setCharacterEncoding("utf-8");
        String action = req.getPathInfo();
        // 新增/修改（含文件上传，15 篇）
        // ... 解析表单 + 头像上传 + 调 service
    }

    private String toJson(Object obj) throws IOException {
        return new ObjectMapper().writeValueAsString(obj);   // Jackson（14 篇）
    }
}
```

> 💡 **这就是 04/14 篇的请求处理 + JSON**：`getPathInfo` 路由分发、`getParameter` 取参、Jackson 序列化 JSON。**做完你会感受到"手动路由分发、手动序列化、手动异常处理"的繁琐**——Spring MVC 的 `@GetMapping`/`@PathVariable`/`@RestController` 全自动化了。


## 📌 在 Spring Boot 中

> 本项目用原生技术栈实现，Spring Boot 会把其中大部分"手动活"自动化。下面对照核心模块，让你看清 Spring Boot 怎么简化本项目。**这不是让你重写本项目，而是让你带着本项目的痛感，理解 Spring Boot 每个特性的价值**。

### 1. 启动初始化：从"StartupListener + ServletContext"到"@Bean + 自动配置"

**原生**：本项目 2.1 用 `ServletContextListener` 手动建 Druid 存 ServletContext。
**Spring Boot**：`@Bean` + 自动配置。

```java
// Spring Boot：连接池自动配，不用写 Listener
// application.yml 配置即可（17 篇讲过）
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/student_db
    username: root
    password: 123456
    # HikariCP 自动配置
```

```java
// 启动钩子用 CommandLineRunner（09 篇讲过）
@Component
public class StartupRunner implements CommandLineRunner {
    @Override
    public void run(String... args) {
        System.out.println("=== 学生管理系统启动 ===");
    }
}
```

> 💡 **原理对应**：本项目手动写的 `StartupListener`（建连接池 + 存 ServletContext），Spring Boot 用 `@Bean` + 自动配置完全替代——连接池自动建、自动注入，不用手动存取。**本项目的"启动初始化"痛点，Spring Boot 自动化了**。

### 2. 鉴权：从"AuthFilter + Session"到"Spring Security"

**原生**：本项目 2.2 手写 `AuthFilter` 判 Session。
**Spring Boot**：Spring Security 配置。

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http.authorizeHttpRequests(auth -> auth
                .requestMatchers("/login", "/static/**").permitAll()
                .anyRequest().authenticated())
            .formLogin(form -> form
                .loginPage("/login").defaultSuccessUrl("/student/list").permitAll())
            .logout(logout -> logout.logoutUrl("/logout").logoutSuccessUrl("/login"));
        return http.build();
    }
}
```

> 💡 **原理对应**：本项目的 `AuthFilter` + `LoginServlet` + `LogoutServlet` 三个组件，Spring Security 用一个配置类替代——登录、注销、鉴权全自动。**本项目的"手写鉴权"痛点，Spring Security 自动化了**。

### 3. Controller：从"Servlet + getPathInfo"到"@RestController"

**原生**：本项目 2.6 用 `HttpServlet` + `getPathInfo` + `switch` 路由。
**Spring Boot**：`@RestController` + `@GetMapping`。

```java
@RestController
@RequestMapping("/api/students")
public class StudentController {
    @Autowired
    private StudentService service;

    @GetMapping
    public PageResult<Student> list(@RequestParam(defaultValue = "1") int page,
                                     @RequestParam(defaultValue = "5") int size,
                                     @RequestParam(required = false) String keyword) {
        return service.list(page, size, keyword);   // 自动序列化为 JSON
    }

    @GetMapping("/{id}")
    public Student get(@PathVariable Long id) { return service.get(id); }

    @DeleteMapping("/{id}")
    public void delete(@PathVariable Long id) { service.delete(id); }

    @PostMapping
    public Student add(@RequestBody Student student) { service.add(student); return student; }
}
```

> 💡 **原理对应**：本项目的 `StudentServlet`（手动路由 + 手动取参 + 手动序列化 + 手动异常处理），Spring Boot 用 `@RestController` + 注解全部替代——路由注解映射、参数自动注入、返回值自动序列化。**本项目的"手动 Controller"痛点，Spring MVC 自动化了**。

### 4. DAO：从"DBUtils + 手写 SQL"到"MyBatis-Plus BaseMapper"

**原生**：本项目 2.4 用 `QueryRunner` 手写每个 SQL。
**Spring Boot**：MyBatis-Plus `BaseMapper`。

```java
// MyBatis-Plus：继承 BaseMapper，通用 CRUD 不写 SQL
@Mapper
public interface StudentMapper extends BaseMapper<Student> {
    // 自带 insert/deleteById/updateById/selectById/selectPage...
}

// Service
@Service
public class StudentService {
    @Autowired
    private StudentMapper mapper;

    public Page<Student> list(int page, int size, String keyword) {
        Page<Student> p = new Page<>(page, size);
        LambdaQueryWrapper<Student> wrapper = new LambdaQueryWrapper<>();
        if (keyword != null) wrapper.like(Student::getName, keyword);
        return mapper.selectPage(p, wrapper);   // 自动分页
    }
}
```

> 💡 **原理对应**：本项目的 `StudentDao`（手写 SQL + 手动分页 + 手动条件拼接），MyBatis-Plus 用 `BaseMapper` + `Page` + `LambdaQueryWrapper` 全部替代——CRUD 不写 SQL、分页自动、条件类型安全。**本项目的"手写 SQL + 分页"痛点，MyBatis-Plus 自动化了**。

### 5. 事务：从"手动 setAutoCommit"到"@Transactional"

**原生**：本项目如果要事务（如批量导入），手动 `setAutoCommit(false)` + `commit`/`rollback`。
**Spring Boot**：`@Transactional`。

```java
@Service
public class StudentService {
    @Transactional   // 自动管事务
    public void batchImport(List<Student> students) {
        for (Student s : students) {
            mapper.insert(s);   // 全成功才提交，任一失败全回滚
        }
    }
}
```

> 💡 **原理对应**：本项目的手动事务管理，Spring 用 `@Transactional` 一个注解替代——自动借连接、关自动提交、提交/回滚。**本项目的"手动事务"痛点，Spring 自动化了**。

### 6. 配置：从"web.xml + 注解 + properties"到"application.yml"

**原生**：本项目用 `@WebServlet`/`@WebFilter`/`@WebListener` 注解 + 手动读配置。

> 💡 **原理对应**：本项目的 `EncodingFilter`、`StartupListener` 连接池、`@MultipartConfig` 限制，Spring Boot 用 `application.yml` 统一配置 + 自动配置替代。**本项目的"配置分散"痛点，Spring Boot 用约定优于配置解决了**。
