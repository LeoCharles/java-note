# Java SE 学习路线图

> 本文档是整个 Java SE 学习笔记的**总导航**，按由浅入深的顺序组织全部知识点文档。
> 每个知识点独立成篇，思路从概念 → 语法 → 代码实例 → 易错点 → 实战案例，以 **Java 8（JDK 1.8，两者为同一版本）** 语法为基础，Java 9+ 新版本特性以「补充说明」形式给出。
> 阅读建议：按编号顺序学习，每篇配合代码动手敲一遍；带 ⭐ 的是开发高频/面试重点，务必吃透。

## 学习建议

1. **按顺序，别跳跃**：阶段二、三、五是核心主干，后面的 IO/并发/反射都依赖它们。
2. **动手敲，别只看**：每篇的代码实例务必在 IDEA 中运行一遍，修改参数观察结果。
3. **重点攻克易错点**：每篇「⚠️ 重点」小节是开发踩坑高发区，带 ⭐ 的章节面试也高频。
4. **以 Java 8 为基准**：所有代码在 Java 8（即 JDK 1.8）下可运行；Java 8 的重要新特性（Lambda/Stream/新时间 API/接口 default 方法）属于基准内容，重点讲解；Java 9+ 特性才以「补充说明」给出。
5. **配合实战**：学完集合 + IO + 异常后，可尝试写一个"通讯录"小项目串联知识点；学完并发后尝试写"多线程下载器"。
