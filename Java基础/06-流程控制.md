# 流程控制

程序默认从上到下逐行执行，但真实业务远比"一条直线"复杂——要根据用户角色显示不同菜单、要循环处理上万条数据、要在满足条件时提前结束。**流程控制**就是让代码具备"判断"与"重复"的能力，是写任何业务逻辑的基石。

> 💡 本篇涉及的控制语句几乎在每一门语言里都有，但 Java 有自己的细节：`switch` 对 `String` 的支持、带标签的 `break`、`case` 穿透等，都是面试与开发的高频考点。

---

## 一、顺序结构

顺序结构是最简单的执行流程：**从上到下，依次执行**，每条语句执行完才进入下一条。

```java
int a = 10;              // 第 1 步
int b = 20;              // 第 2 步
int sum = a + b;         // 第 3 步
System.out.println(sum); // 第 4 步，输出 30
```

> 📌 **规范**：顺序结构是默认行为，不需要关键字。但要注意——一条语句一个分号，不要把多条逻辑挤在一行，影响可读性。

## 二、判断语句

### 2.1 if 语句

`if` 满足条件才执行，否则跳过：

```java
int score = 85;
if (score >= 60) {
    System.out.println("及格了");   // ✅ 条件为 true 执行
}
// score=85，输出"及格了"
```

### 2.2 if-else 语句

二选一：条件为 `true` 走 `if`，否则走 `else`。

```java
int age = 16;
if (age >= 18) {
    System.out.println("成年人");
} else {
    System.out.println("未成年");   // ✅ 走 else
}
```

### 2.3 if-else if-else（多条件判断）

多个条件依次判断，**一旦某个条件为 true，执行后跳出整个 if 结构**，不再判断后续条件：

```java
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");   // ✅ 命中这里，后面不再判断
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
// 输出"良好"
```

> ⚠️ **条件顺序很重要**：判断区间要从大到小或从小到大依次排列。如果先写 `score >= 60`，那 85 也会先命中它，后面的 `>= 80` 永远走不到。

```java
// ❌ 错误顺序：85 会先命中 >=60
int score = 85;
if (score >= 60) {
    System.out.println("及格");   // 85 命中这里就结束了
} else if (score >= 80) {
    System.out.println("良好");  // 永远走不到
}
```

> 💡 **建议**：无论 `if` 体有几行，都加上大括号 `{}`。省略大括号只对单条语句生效，极易引发 bug（如苹果的 `goto fail` 漏洞）。

## 三、选择语句 switch

`switch` 根据**一个变量的值**跳转到匹配的 `case`，比多层 `if-else if` 更清晰，适合"一个值对应多种分支"的场景。

### 3.1 基本格式

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    case 3:
        System.out.println("星期三");   // ✅ 命中
        break;
    case 4:
        System.out.println("星期四");
        break;
    default:
        System.out.println("未知");
        break;
}
// 输出"星期三"
```

### 3.2 case 穿透（不写 break）⭐

`switch` 的 `case` 本质是"跳转标记"——匹配后从该 `case` 开始执行，**直到遇到 `break` 或 `}` 才结束**。漏写 `break` 会"穿透"到下一个 `case`：

```java
int day = 2;
switch (day) {
    case 1:
        System.out.println("星期一");
        // 没写 break
    case 2:
        System.out.println("星期二");   // ✅ 命中
        // 没写 break，继续往下穿透
    case 3:
        System.out.println("星期三");   // ⚠️ 穿透执行
    default:
        System.out.println("未知");      // ⚠️ 继续穿透
}
// 输出：星期二 / 星期三 / 未知
```

> ⚠️ **穿透是 bug 的常见来源**：忘记写 `break` 会导致意料之外的执行。但有时也可利用穿透合并相同分支：

```java
// ✅ 利用穿透：工作日/周末合并
int day = 6;
switch (day) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        System.out.println("工作日");   // 1~5 都穿透到这里
        break;
    case 6:
    case 7:
        System.out.println("周末");     // 6、7 穿透到这里
        break;
    default:
        System.out.println("非法输入");
}
```

### 3.3 default

`default` 是所有 `case` 都不匹配时执行的分支，类似 `if-else` 末尾的 `else`。位置可以放在任意处，但**习惯放最后**。

```java
int x = 99;
switch (x) {
    case 1:
        System.out.println("一");
        break;
    default:
        System.out.println("不是 1");   // ✅ 命中 default
        break;
}
```

### 3.4 case 的值要求 ⭐

`switch` 表达式的类型有限制：

| 支持的类型 | 说明 |
| :--- | :--- |
| `byte` / `short` / `char` / `int` | 基本类型（不含 long/float/double/boolean） |
| **枚举**（Java 5+） | `enum` 类型 |
| `String`（**Java 7+**） | 字符串匹配 |
| 包装类 `Byte`/`Short`/`Integer`/`Character` | 自动拆箱 |

```java
// ✅ Java 7+ 支持 String
String command = "start";
switch (command) {
    case "start":
        System.out.println("启动");
        break;
    case "stop":
        System.out.println("停止");
        break;
    default:
        System.out.println("未知命令");
}

// ❌ 不支持 long、float、double、boolean
// long l = 1L; switch (l) { ... }  // 编译错误
```

> ⚠️ **case 的值必须是常量**（字面量或 `final` 变量），不能是变量或运行时表达式。`case` 值不能重复。

```java
final int A = 1;
int b = 2;
switch (x) {
    case A:        // ✅ final 常量
    // case b:    // ❌ b 不是常量
}
```

## 四、循环语句

### 4.1 for 循环

`for` 适合**循环次数已知**的场景，格式：`初始化; 条件; 步进`。

```java
// 打印 1~5
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

// 求和：1 加到 100
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
System.out.println(sum);   // 5050
```

> 💡 循环变量 `i` 的作用域仅限 `for` 内部，出了循环就不能用。

### 4.2 while 循环

`while` 先判断条件，为 true 才执行循环体。适合**循环次数未知、靠条件退出**的场景。

```java
// 打印 1~5
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
```

### 4.3 do-while 循环

`do-while` **先执行一次循环体，再判断条件**——至少执行一次。

```java
// 至少执行一次
int i = 10;
do {
    System.out.println(i);   // ✅ 先执行，输出 10
    i++;
} while (i <= 5);           // 再判断，10<=5 为 false，结束
```

### 4.4 三种循环的区别与选择

| 循环 | 执行次数 | 何时判断条件 | 典型场景 |
| :--- | :---: | :---: | :--- |
| `for` | 已知 | 先判断 | 遍历数组、固定次数 |
| `while` | 未知 | 先判断 | 读取数据直到结束 |
| `do-while` | 至少 1 次 | 后判断 | 菜单输入、先执行再校验 |

> 💡 **选择原则**：次数明确用 `for`；次数不明用 `while`；至少要执行一次用 `do-while`。

```java
// 场景对比：菜单输入（至少展示一次菜单）
Scanner sc = new Scanner(System.in);
int choice;
do {
    System.out.println("1.开始 2.退出");
    choice = sc.nextInt();
} while (choice != 2);   // 选 2 才退出，否则继续展示菜单
```

## 五、break 和 continue

### 5.1 break：跳出循环

`break` 立即结束**当前所在循环**：

```java
// 找到第一个能被 3 整除的数就停
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) {
        System.out.println(i);   // 3
        break;                   // 找到就跳出，不再继续
    }
}
```

### 5.2 continue：跳过本次

`continue` 跳过本次循环体剩余部分，**直接进入下一次循环**：

```java
// 打印 1~10 中所有奇数
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;   // 偶数跳过，不打印
    }
    System.out.println(i);   // 1 3 5 7 9
}
```

> ⚠️ **区别**：`break` 是"我不干了"（结束整个循环）；`continue` 是"这次不干了"（跳过本次，继续下一次）。

### 5.3 带标签的 break：跳出多层嵌套 ⭐

普通 `break` 只能跳出**一层**循环。要跳出多层，用**带标签的 break**：

```java
// 在二维数组中查找目标值，找到就全部跳出
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
int target = 5;
boolean found = false;

outer:                              // ✅ 标签
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        if (matrix[i][j] == target) {
            found = true;
            System.out.println("找到 " + target + "，位置 [" + i + "][" + j + "]");
            break outer;            // ✅ 跳出外层循环
        }
    }
}
// 输出：找到 5，位置 [1][1]
```

> 💡 标签名自定义（如 `outer`、`loop1`），后面跟冒号 `:`。`continue` 也可带标签，跳到外层循环的下一次迭代。

```java
// 带标签的 continue：跳过外层本次
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == j) {
            continue outer;   // i==j 时跳过外层本次
        }
        System.out.println(i + "," + j);
    }
}
// 输出 2,1 / 3,1 / 3,2（跳过了 1,1 / 2,2 / 3,3）
```

## 六、死循环与 while(true) 的应用场景

死循环是**永不结束的循环**（条件永远为 true）。看似危险，实际开发中却很常用：

```java
// ✅ 经典写法 1：while(true)
while (true) {
    // ...
}

// ✅ 经典写法 2：for(;;)
for (;;) {
    // ...
}
```

### 典型应用场景

```java
// 场景 1：服务端持续监听请求（配合多线程）
while (true) {
    Socket client = server.accept();   // 阻塞等待连接
    handleRequest(client);
}

// 场景 2：游戏主循环
while (running) {
    processInput();
    updateState();
    render();
}

// 场景 3：菜单反复输入，直到选择退出
Scanner sc = new Scanner(System.in);
while (true) {
    System.out.println("1.查询 2.修改 3.退出");
    int choice = sc.nextInt();
    if (choice == 3) {
        System.out.println("退出");
        break;          // ✅ 用 break 跳出死循环
    }
    // 处理 choice...
}
```

> ⚠️ 死循环必须有**退出机制**（`break`、`return`、外部条件），否则程序会卡死。服务端场景下，退出通常由进程信号（如 kill）触发。

## 七、嵌套循环

循环内部再套循环，常用于二维数据遍历、打印图形、组合枚举。

### 7.1 九九乘法表

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "x" + i + "=" + (i * j) + "\t");
    }
    System.out.println();   // 每行结束换行
}
// 输出：
// 1x1=1
// 1x2=2  2x2=4
// 1x3=3  2x3=6  3x3=9
// ...
```

### 7.2 打印直角三角形

```java
for (int i = 1; i <= 5; i++) {       // 行数
    for (int j = 1; j <= i; j++) {   // 每行星数 = 行号
        System.out.print("*");
    }
    System.out.println();
}
// 输出：
// *
// **
// ***
// ****
// *****
```

### 7.3 打印倒三角

```java
for (int i = 5; i >= 1; i--) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
// *****
// ****
// ***
// **
// *
```

> ⚠️ **嵌套循环的复杂度是乘级**：外层 n 次 × 内层 m 次 = n×m 次。层数越多性能越差，实际开发中三层以上嵌套要警惕性能。

## ⚠️ 重点

### 重点 1：switch 必须写 break（除非有意穿透）⭐⭐

```java
// ❌ 忘记 break，case 穿透
int day = 1;
switch (day) {
    case 1:
        System.out.println("星期一");
    case 2:
        System.out.println("星期二");
    default:
        System.out.println("未知");
}
// 输出：星期一 / 星期二 / 未知  ← 全部穿透了
```

> 📌 **规范**：每个 `case` 末尾必须写 `break`（包括 `default`）。若有意穿透，必须加注释说明，避免被误判为 bug。

### 重点 2：switch 支持 String 是 Java 7+ 特性 ⭐

```java
String s = "a";
switch (s) {        // Java 7+ 才支持
    case "a":
        System.out.println("A");
        break;
}
```

> ⚠️ `switch` 比较 String 用的是 `.equals()`，所以**不会出现 `==` 比较的地址坑**。但 `null` 仍会抛 `NullPointerException`。

### 重点 3：break 与 continue 的作用范围

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            break;      // 只跳出内层循环，外层继续
        }
        System.out.println(i + "," + j);
    }
}
// 输出：1,1 / 2,1 / 3,1（内层 j=2 时跳出，但外层 i 继续）
```

> ⚠️ 普通 `break`/`continue` 只作用于**最近一层循环**。要跳出多层必须用带标签的形式。

### 重点 4：for 循环条件为空表示 true

```java
for (;;) { }          // 等价于 while(true)，死循环
for (int i = 0; ; i++) { }  // 无条件判断 = 永远 true
```

### 重点 5：浮点数做循环条件要小心

```java
// ❌ 浮点精度问题可能导致多循环或少循环一次
for (double d = 0.1; d != 1.0; d += 0.1) {
    System.out.println(d);   // 可能永远不等于 1.0，死循环
}

// ✅ 用整数循环，再换算
for (int i = 1; i <= 10; i++) {
    double d = i / 10.0;
    System.out.println(d);
}
```

> ⚠️ **铁律**：循环条件**不要用浮点数判断**，用整数计数器更安全（呼应 [04-数据类型与类型转换](04-数据类型与类型转换.md) 的精度问题）。

## 💻 实战案例

### 案例 1：根据用户角色显示不同菜单（switch）⭐

后台系统中，不同角色（管理员、运营、普通用户）看到的菜单不同：

```java
String role = "admin";
switch (role) {
    case "admin":
        System.out.println("【管理后台】");
        System.out.println("1.用户管理 2.系统配置 3.数据统计 4.日志审计");
        break;
    case "operator":
        System.out.println("【运营后台】");
        System.out.println("1.商品管理 2.订单管理 3.活动配置");
        break;
    case "user":
        System.out.println("【用户中心】");
        System.out.println("1.我的订单 2.个人资料 3.退出登录");
        break;
    default:
        System.out.println("未知角色，请联系管理员");
}
```

> 💡 实际项目中角色权限通常用 RBAC 表驱动，但小型系统用 `switch` 直观高效。

### 案例 2：表单校验多条件判断（if-else if）

用户注册时校验用户名、密码、邮箱：

```java
String username = "leo";
String password = "123";
String email = "leo@mail.com";

if (username == null || username.length() < 3) {
    System.out.println("❌ 用户名至少 3 位");
} else if (password == null || password.length() < 6) {
    System.out.println("❌ 密码至少 6 位");   // ✅ 命中
} else if (email == null || !email.contains("@")) {
    System.out.println("❌ 邮箱格式不正确");
} else {
    System.out.println("✅ 校验通过，可以注册");
}
```

> 📌 **规范**：校验顺序应"先快后慢"——最容易失败、成本最低的校验放前面，避免无谓的复杂判断。

### 案例 3：分页计算

分页是后台系统的高频需求：已知总数和每页条数，计算总页数和当前页起止下标。

```java
int total = 105;          // 总记录数
int pageSize = 10;        // 每页 10 条

// ✅ 总页数：向上取整的经典写法
int totalPages = (total + pageSize - 1) / pageSize;
System.out.println("总页数：" + totalPages);   // 11

// 当前页数据范围
int currentPage = 7;
int startIndex = (currentPage - 1) * pageSize;   // 60
int endIndex = Math.min(startIndex + pageSize, total);  // 70
System.out.println("第 " + currentPage + " 页：" + startIndex + "~" + (endIndex - 1));

// 用循环模拟分页遍历
for (int page = 1; page <= totalPages; page++) {
    int start = (page - 1) * pageSize;
    int end = Math.min(start + pageSize, total);
    System.out.println("第 " + page + " 页：" + start + " ~ " + (end - 1));
}
```

> ⚠️ **分页公式**：`(total + pageSize - 1) / pageSize` 是整数向上取整的标准写法，比 `Math.ceil` 更安全（避免浮点误差）。

### 案例 4：批量数据处理循环

遍历订单数组，统计金额超过 1000 的订单数和总金额：

```java
double[] orders = {1200, 800, 3500, 600, 2100, 100};
int count = 0;
double sum = 0;

for (int i = 0; i < orders.length; i++) {
    if (orders[i] > 1000) {
        count++;
        sum += orders[i];
    }
}
System.out.println("大额订单数：" + count + "，总金额：" + sum);
// 大额订单数：3，总金额：6800.0
```

> 💡 实际开发中金额用 `BigDecimal`，这里为演示循环逻辑用 `double`。

### 案例 5：用 while 读取直到文件结束

读取输入流直到没有数据，是 `while` 的经典场景（循环次数未知）：

```java
import java.util.Scanner;

// 模拟：从控制台读取整数，输入 0 结束，统计正数个数
Scanner sc = new Scanner(System.in);
int positiveCount = 0;
int n;
while ((n = sc.nextInt()) != 0) {   // 输入 0 退出
    if (n > 0) {
        positiveCount++;
    }
}
System.out.println("正数个数：" + positiveCount);
```

```java
// 真实场景：逐行读取文件直到末尾
import java.io.BufferedReader;
import java.io.FileReader;

BufferedReader reader = new BufferedReader(new FileReader("data.txt"));
String line;
while ((line = reader.readLine()) != null) {   // 读到 null 表示结束
    System.out.println(line);
    // 处理每一行...
}
reader.close();
```

> 💡 `while ((x = next()) != null)` 是读取流/集合的经典模式——条件既赋值又判断，紧凑高效。

### 案例 6：带标签 break 跳出多层嵌套查找 ⭐

在二维订单矩阵中查找指定订单号，找到立即结束全部循环：

```java
String[][] orders = {
    {"ORD001", "ORD002", "ORD003"},
    {"ORD004", "ORD005", "ORD006"},
    {"ORD007", "ORD008", "ORD009"}
};
String target = "ORD005";
int foundRow = -1, foundCol = -1;

search:
for (int i = 0; i < orders.length; i++) {
    for (int j = 0; j < orders[i].length; j++) {
        if (orders[i][j].equals(target)) {
            foundRow = i;
            foundCol = j;
            break search;        // ✅ 一次性跳出两层
        }
    }
}

if (foundRow != -1) {
    System.out.println("找到 " + target + "，位于第 " + (foundRow + 1) + " 行第 " + (foundCol + 1) + " 列");
} else {
    System.out.println("未找到");
}
```

> 💡 不用带标签 break 的话，需要额外 `boolean found` 标志位配合每层判断，代码更啰嗦。带标签 break 在查找类场景非常实用。

### 案例 7：do-while 实现菜单反复输入

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
int choice;
do {
    System.out.println("===== 订单系统 =====");
    System.out.println("1. 查询订单");
    System.out.println("2. 创建订单");
    System.out.println("3. 修改订单");
    System.out.println("0. 退出");
    System.out.print("请选择：");
    choice = sc.nextInt();

    switch (choice) {
        case 1:
            System.out.println("执行查询...");
            break;
        case 2:
            System.out.println("执行创建...");
            break;
        case 3:
            System.out.println("执行修改...");
            break;
        case 0:
            System.out.println("感谢使用，再见！");
            break;
        default:
            System.out.println("输入有误，请重新输入");
    }
} while (choice != 0);   // 选 0 才退出
```

> 💡 `do-while` 保证菜单**至少展示一次**，是命令行交互程序的标配结构。

## 🚀 新版本补充

### Java 5+：增强 for 循环（for-each）

遍历数组/集合更简洁，无需手动管理下标：

```java
int[] nums = {1, 2, 3, 4, 5};
for (int num : nums) {        // ✅ 增强 for
    System.out.println(num);
}
// 等价于
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}
```

> ⚠️ 增强 for **无法获取下标**，也**不能在遍历时修改集合**（会抛 `ConcurrentModificationException`）。需要下标或边遍历边删除时，仍用传统 `for`。

### Java 8+：switch 对枚举的增强

枚举配合 `switch` 是非常优雅的写法，类型安全且 IDE 可检查穷尽性：

```java
enum OrderStatus { PENDING, PAID, SHIPPED, COMPLETED, CANCELED }

OrderStatus status = OrderStatus.PAID;
switch (status) {
    case PENDING:
        System.out.println("待支付");
        break;
    case PAID:
        System.out.println("已支付，待发货");   // ✅
        break;
    case SHIPPED:
        System.out.println("已发货");
        break;
    case COMPLETED:
        System.out.println("已完成");
        break;
    case CANCELED:
        System.out.println("已取消");
        break;
}
```

### Java 12+：switch 表达式（预览），Java 14 正式

`switch` 升级为表达式，可直接返回值，用 `->` 箭头语法，**自动不穿透**：

```java
// Java 14+ 正式语法
String desc = switch (status) {
    case PENDING -> "待支付";
    case PAID -> "已支付";
    case SHIPPED, COMPLETED -> "已处理";
    case CANCELED -> "已取消";
};
System.out.println(desc);
```

> 💡 Java 8 环境下不可用，了解即可。新语法省去了大量 `break`，从根上消除了穿透 bug。

### Java 9+：带标签的 break 在增强循环中的配合

```java
// Java 8 也可用：增强 for + 带标签 break
int[][] data = {{1, 2}, {3, 4}, {5, 6}};
outer:
for (int[] row : data) {
    for (int v : row) {
        if (v == 3) {
            System.out.println("找到 3");
            break outer;
        }
    }
}
```

## 本章小结

| 知识点 | 要点 |
| :--- | :--- |
| 顺序结构 | 从上到下依次执行，默认行为 |
| if / if-else | 二选一，条件为 true 走 if |
| if-else if-else | 多条件，命中即停，注意区间顺序 |
| switch | 一个值多分支，支持 byte/short/char/int/枚举/String(7+) |
| case 穿透 | 不写 break 会向下穿透，可利用合并分支 |
| for | 循环次数已知，初始化+条件+步进 |
| while | 循环次数未知，先判断 |
| do-while | 至少执行一次，后判断 |
| break | 跳出当前循环 |
| continue | 跳过本次，进入下一次 |
| 带标签 break | 跳出多层嵌套 |
| 死循环 | while(true)/for(;;)，需有退出机制 |

## 学习建议

1. **亲手敲一遍九九乘法表和三角形打印**：嵌套循环是初学者第一个"思维坎"，光看懂不够，必须自己写出外层行、内层列的关系，肌肉记忆才牢固。
2. **刻意练习 case 穿透**：写一个漏 `break` 的 `switch`，观察输出，再写一个"利用穿透合并工作日"的版本，理解穿透的两面性。
3. **记住 switch 的类型限制**：能放 `String`（Java 7+）但不能放 `long`/`boolean`，这是面试高频题；`case` 值必须是常量。
4. **区分 break 与 continue 的作用层**：在嵌套循环里各写一遍，观察普通 `break` 只跳一层、带标签 `break` 跳多层，这是真实开发中查找/退出场景的利器。
5. **避免浮点做循环条件**：循环计数器永远用 `int`，需要小数时再换算——这是避免死循环和差一错误的关键习惯。
