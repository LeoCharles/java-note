# Spring Boot 学习路线图

> 本文档是整个 Spring Boot 学习笔记的**总导航**，按由浅入深的顺序组织全部 54 篇知识点文档。
> 前置基础：已学完 [Java SE 学习路线图](../Java基础/00-学习路线图.md) 与 [Java Web 学习路线图](../JavaWeb/00-学习路线图.md)。JavaWeb 学的是"底层原理"（Servlet/JSP/JDBC/连接池），本路线图学的是"工程效率"——用 Spring Boot 把那些手写的样板代码全部封装掉。
> 学习定位：**面向企业级开发**。目标是学完后能独立用 Spring Boot 搭建一个带数据库、缓存、认证、消息队列、容器化部署的后端服务。
> 阅读建议：按阶段顺序学习，带 ⭐ 的是企业开发高频/面试重点，务必吃透；标「选学」的按需了解，不必全学。本目录另有 [Spring Boot 快速上手文档.md](Spring%20Boot%20快速上手文档.md)（速查向）、[注解速查手册.md](注解速查手册.md)、[Maven 使用文档.md](Maven%20使用文档.md) 可作参考。

## 这份路线图的设计理念

在开始列知识点之前，先说清楚"为什么这么排"：

1. **54 篇文档原本是"前端开发者速成"视角**。这套教程的原始定位是让前端开发者快速看懂、能改 Spring Boot 代码，每篇都对应一个 demo 模块。内容本身完整有效，但对"系统学 Java 后端做企业级开发"的人来说，需要一个**有主次、有顺序**的路线图重新组织——这正是本文档做的事。
2. **先骨架后血肉**。阶段一先把"任何 Spring Boot 应用都要有的骨架"搭起来（项目创建、配置、日志、AOP、异常处理、监控），后续每个阶段往这个骨架上挂一块能力。**不要一上来就钻 MyBatis/Redis**，先把骨架立住。
3. **数据库访问是最大的一块**。阶段三有 6 篇 ORM 文档，不要全学——`JdbcTemplate` 理解原理即可，生产主力是 **MyBatis + MyBatis-Plus**，JPA/BeetlSQL 按需了解。
4. **每个知识点都回扣 JavaWeb 原理**。你刚学完 Servlet/JDBC/连接池/Filter/Session，本路线图会让你看到：Spring Boot 的 `@RestController` 封装了 Servlet，`@Transactional` 封装了 JDBC 事务，HikariCP 就是连接池篇讲的那套。**带着"它封装了我学过的什么"的视角学**。
5. **核心 vs 选学分明**。企业开发有些能力是"几乎所有项目都要"（配置、日志、数据库、认证、缓存），有些是"特定场景才要"（Neo4j、UReport2、LDAP）。⭐ 标核心，选学的不必硬啃。

## 阶段一：工程入门与骨架

> 这是任何 Spring Boot 应用的"骨架"。先把这 7 篇吃透，后续每个阶段都是往这个骨架上挂能力。

  - 📌 回扣 JavaWeb：[02-Servlet 入门](../JavaWeb/02-Servlet%20入门.md)——`DispatcherServlet` 本身就是一个 Servlet，`@RestController` 的方法由它分发

  - `application.yml` 配置；`@Value`/`@ConfigurationProperties` 读取；多环境 profile；配置优先级

  - Actuator 健康检查/指标/环境信息；`/actuator/health`；暴露端点配置

## 阶段三：数据库访问层

> 这是最大、最重要的一阶段。6 篇 ORM 文档代表"简化 JDBC 样板"的不同进化程度，对应 [18-Apache DBUtils](../JavaWeb/18-Apache%20DBUtils.md) 讲过的进化链。**生产主力是 MyBatis + MyBatis-Plus**，JdbcTemplate 理解原理，JPA/BeetlSQL 按需。

  - 📌 回扣 JavaWeb：[18-Apache DBUtils](../JavaWeb/18-Apache%20DBUtils.md)——`JdbcTemplate` 就是 `QueryRunner` 的 Spring 版，`BeanPropertyRowMapper` 对应 `BeanHandler`
- [14-数据库操作_JPA](14-数据库操作_JPA.md)
  - Spring Data JPA；`@Entity`/`@Repository`；`JpaRepository` 接口方法名查询；JPA vs MyBatis 选型
  - 选学/进阶：JPA 适合简单 CRUD，复杂 SQL 不如 MyBatis 灵活
- [15-数据库操作_MyBatis](15-数据库操作_MyBatis.md) ⭐
  - MyBatis 集成；`@Mapper` 接口；`@Select`/`@Insert` 注解；XML 映射；`#{}` 参数；`resultMap`

- [17-数据库操作_MyBatisPlus](17-数据库操作_MyBatisPlus.md) ⭐

学完本路线图后，你已具备 Spring Boot 企业级开发的完整能力。回看与前瞻：

| 方向 | 说明 | 对应笔记 |

| 回看：Java SE 基础 | 反射（MyBatis 代理）、集合（数据结构）、并发（线程池/异步）、IO（文件上传） | [Java基础/00-学习路线图](../Java基础/00-学习路线图.md)（49 篇） |

## 学习建议

1. **先把骨架立住**：阶段一务必先跑通 HelloWorld，理解"自动配置 + 内嵌 Tomcat + 注解驱动"这套范式，再往后学。不要一上来就钻 MyBatis/Redis。
2. **ORM 选型要聚焦**：阶段三 6 篇不要全学。`JdbcTemplate`（13）理解原理，**MyBatis（15）+ 通用 Mapper（16）+ MyBatis-Plus（17）是生产主力**，JPA（14）/BeetlSQL（18）按需了解。学完 MyBatis-Plus 你就能做大部分 CRUD 业务。
3. **带着 JavaWeb 的痛感学**：每学一个 Spring Boot 特性，回想 JavaWeb 里手写有多繁琐——`@RestController` vs 手写 Servlet，`@Transactional` vs 手动管连接事务，`@Cacheable` vs 手动管缓存。**痛感越深，理解越透**。
4. **Security 要结合 Filter 学**：Spring Security 学习曲线陡，但它的过滤链本质就是 [08-Filter 过滤器](../JavaWeb/08-Filter%20过滤器.md) 讲的那套。先复习 Filter 篇再学 Security，事半功倍。
5. **选学的不必硬啃**：标「选学」的文档（Neo4j、LDAP、UReport2、SocketIO 等）是特定场景才用，了解存在即可，用到再学。**不要试图把 54 篇全学完再开始做项目**——学完核心（⭐）篇就能做项目了。
6. **动手做项目**：学完阶段一到六（骨架 + Web + 数据库 + 缓存 + 通用能力 + 安全），就可以独立做一个带登录鉴权 + CRUD + 缓存 + 定时任务的后台系统了。**做项目比刷文档更有效**。
7. **Docker 要早学**：阶段十一的 Docker（42）建议在学完阶段三后就穿插学——本地跑 MySQL/Redis/ RabbitMQ 用 Docker 一条命令启动，比手动装省太多事。
8. **参考文档配合用**：[注解速查手册.md](注解速查手册.md) 可随时查注解用法，[Spring Boot 快速上手文档.md](Spring%20Boot%20快速上手文档.md) 是速查向的总览，[Maven 使用文档.md](Maven%20使用文档.md) 在依赖管理遇到问题时参考。
