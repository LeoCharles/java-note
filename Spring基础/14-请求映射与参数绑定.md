# 请求映射与参数绑定

上一篇学了 Spring MVC 的整体架构——DispatcherServlet 作为前端控制器分发请求。本篇聚焦在日常开发中使用频率最高的部分：**怎么写接口、怎么接收参数、怎么校验参数、怎么返回统一格式**。这是每个 Spring Boot 开发者每天都要写的东西。

> 💡 参数绑定是 Spring MVC 最强大的特性之一——一个注解就把 HTTP 请求的参数变成了 Java 对象，背后是一整套参数解析器在默默工作。

---

## 一、请求映射注解

### 1.1 六个映射注解

| 注解 | HTTP 方法 | 用途 |
| :--- | :--- | :--- |
| `@RequestMapping` | 不限 | 通用，可指定 method 属性 |
| `@GetMapping` | GET | 查询资源 |
| `@PostMapping` | POST | 创建资源 |
| `@PutMapping` | PUT | 更新资源（全量） |
| `@PatchMapping` | PATCH | 更新资源（部分） |
| `@DeleteMapping` | DELETE | 删除资源 |

```java
@RestController
@RequestMapping("/users")   // 类级别：所有方法的公共路径前缀
public class UserController {

    @GetMapping                  // GET /users
    public List<User> list() { ... }

    @GetMapping("/{id}")        // GET /users/1
    public User getById(@PathVariable Long id) { ... }

    @PostMapping                // POST /users
    public User create(@RequestBody User user) { ... }

    @PutMapping("/{id}")        // PUT /users/1
    public User update(@PathVariable Long id, @RequestBody User user) { ... }

    @DeleteMapping("/{id}")     // DELETE /users/1
    public void delete(@PathVariable Long id) { ... }
}
```

### 1.2 @RequestMapping 的常用属性

```java
@RequestMapping(
    value = "/users",              // 路径
    method = {RequestMethod.GET, RequestMethod.POST},  // HTTP 方法
    produces = "application/json",  // 请求头 Accept 匹配
    consumes = "application/json",  // 请求头 Content-Type 匹配
    headers = "X-API-Version=2",   // 特定请求头
    params = "type=admin"           // 特定请求参数
)
```

> 💡 实际开发中直接用 `@GetMapping`/`@PostMapping` 等快捷注解，很少裸用 `@RequestMapping`。

## 二、参数绑定 ⭐⭐

### 2.1 参数绑定全家桶

| 注解 | 绑定来源 | 示例 |
| :--- | :--- | :--- |
| `@RequestParam` | URL 查询参数 / 表单 | `?name=张三&age=20` |
| `@PathVariable` | URL 路径变量 | `/users/{id}` |
| `@RequestBody` | 请求体（JSON） | `{"name":"张三","age":20}` |
| `@RequestHeader` | 请求头 | `Authorization: Bearer xxx` |
| `@CookieValue` | Cookie | `JSESSIONID=xxx` |
| `@ModelAttribute` | 表单字段 / 查询参数 | `?name=张三&age=20` → 对象 |

### 2.2 @RequestParam：查询参数

```java
// GET /users?name=张三&age=20&tags=java&tags=spring
@GetMapping
public List<User> search(
        @RequestParam("name") String name,         // name=张三 → "张三"
        @RequestParam(defaultValue = "18") Integer age,  // 不传时默认18
        @RequestParam(required = false) String email,    // 可选参数
        @RequestParam List<String> tags                  // tags=java&tags=spring → [java, spring]
) {
    // ...
}
```

```java
// 全部参数用 Map 接收（不常用，适合动态查询）
@GetMapping
public List<User> search(@RequestParam Map<String, String> params) {
    String name = params.get("name");
    // ...
}
```

### 2.3 @PathVariable：路径变量

```java
// GET /users/1/orders/100
@GetMapping("/{userId}/orders/{orderId}")
public Order getOrder(
        @PathVariable("userId") Long userId,
        @PathVariable("orderId") Long orderId
) {
    return orderService.findById(userId, orderId);
}

// 如果路径变量名和方法参数名一致，可以省略 value
@GetMapping("/{id}")
public User getById(@PathVariable Long id) { ... }  // ← 自动匹配 {id}
```

### 2.4 @RequestBody：JSON 请求体

```java
// POST /users
// Content-Type: application/json
// {"name":"张三","age":20,"email":"zhangsan@example.com"}
@PostMapping
public User create(@RequestBody CreateUserRequest request) {
    return userService.create(request);
}
```

Jackson 自动将 JSON 反序列化为 Java 对象。Spring Boot 默认使用 Jackson，无需配置。

### 2.5 @RequestHeader：请求头

```java
@GetMapping("/me")
public User currentUser(
        @RequestHeader("Authorization") String token,   // 获取 Token
        @RequestHeader(value = "X-Request-Id", required = false) String requestId
) {
    return userService.findByToken(token);
}
```

### 2.6 @CookieValue：Cookie

```java
@GetMapping("/session")
public String session(@CookieValue("JSESSIONID") String sessionId) {
    return "Session ID: " + sessionId;
}
```

## 三、参数校验 @Valid

### 3.1 基本校验注解

```java
@Data
public class CreateUserRequest {
    @NotBlank(message = "用户名不能为空")
    private String name;

    @NotNull(message = "年龄不能为空")
    @Min(value = 0, message = "年龄不能小于0")
    @Max(value = 150, message = "年龄不能大于150")
    private Integer age;

    @Email(message = "邮箱格式不正确")
    private String email;

    @Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式不正确")
    private String phone;

    @Size(min = 6, max = 20, message = "密码长度6-20位")
    private String password;

    @NotEmpty(message = "标签不能为空")
    private List<String> tags;
}
```

### 3.2 Controller 中启用校验

```java
@PostMapping
public User create(@Valid @RequestBody CreateUserRequest request) {
    // @Valid 触发 JSR303 校验 → 失败抛 MethodArgumentNotValidException
    return userService.create(request);
}
```

### 3.3 全局校验异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidation(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
                .map(fieldError -> fieldError.getField() + ": " + fieldError.getDefaultMessage())
                .collect(Collectors.joining("; "));
        return Result.fail(400, message);
    }
}
```

**请求示例**：

```json
// POST /users  请求体：
{"name":"","age":-1,"email":"not-an-email"}

// 响应：
{
    "code": 400,
    "message": "name: 用户名不能为空; age: 年龄不能小于0; email: 邮箱格式不正确"
}
```

## 四、统一返回格式

### 4.1 定义统一响应体

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class Result<T> {
    private int code;
    private String message;
    private T data;

    public static <T> Result<T> success(T data) {
        return new Result<>(200, "success", data);
    }

    public static <T> Result<T> fail(int code, String message) {
        return new Result<>(code, message, null);
    }

    public static <T> Result<T> fail(String message) {
        return new Result<>(500, message, null);
    }
}
```

### 4.2 对返回值做统一包装（可选）

```java
@RestControllerAdvice
public class ResponseAdvice implements ResponseBodyAdvice<Object> {

    @Override
    public boolean supports(MethodParameter returnType, Class converterType) {
        // 如果已经包装过了，不再包装
        return !returnType.getParameterType().equals(Result.class);
    }

    @Override
    public Object beforeBodyWrite(Object body, MethodParameter returnType,
                                  MediaType contentType, Class converterType,
                                  ServerHttpRequest request, ServerHttpResponse response) {
        // 自动包装为 Result
        return Result.success(body);
    }
}
```

## 💻 实战案例

### 案例：完整的 CRUD Controller

```java
@RestController
@RequestMapping("/api/users")
@RequiredArgsConstructor
@Validated  // 允许在方法参数上使用校验注解
public class UserController {
    private final UserService userService;

    // 分页查询
    @GetMapping
    public Result<PageResult<UserVO>> list(
            @RequestParam(defaultValue = "1") int page,
            @RequestParam(defaultValue = "10") int size,
            @RequestParam(required = false) String keyword) {
        return Result.success(userService.search(keyword, page, size));
    }

    // 查询单个
    @GetMapping("/{id}")
    public Result<UserVO> getById(@PathVariable @Min(1) Long id) {
        return Result.success(userService.getById(id));
    }

    // 创建
    @PostMapping
    public Result<UserVO> create(@Valid @RequestBody CreateUserRequest request) {
        return Result.success(userService.create(request));
    }

    // 更新
    @PutMapping("/{id}")
    public Result<UserVO> update(
            @PathVariable Long id,
            @Valid @RequestBody UpdateUserRequest request) {
        return Result.success(userService.update(id, request));
    }

    // 删除
    @DeleteMapping("/{id}")
    public Result<Void> delete(@PathVariable Long id) {
        userService.delete(id);
        return Result.success(null);
    }

    // 批量删除
    @DeleteMapping("/batch")
    public Result<Void> batchDelete(@RequestBody List<Long> ids) {
        userService.batchDelete(ids);
        return Result.success(null);
    }
}
```

## 🎯 面试高频

### Q1：@RequestParam 和 @RequestBody 的区别？

**答**：
- `@RequestParam`：从 URL 查询参数（`?key=value`）或表单（`application/x-www-form-urlencoded`）中获取
- `@RequestBody`：从请求体（`application/json`）中获取，Jackson 自动反序列化为 Java 对象
- GET 请求通常用 `@RequestParam`，POST/PUT 请求通常用 `@RequestBody`

### Q2：@Valid 和 @Validated 有什么区别？

**答**：
- `@Valid` 是 JSR-303 标准注解（`javax.validation`）
- `@Validated` 是 Spring 的增强版，支持分组校验、方法级校验
- Controller 方法参数上两者都可使用
- Service 层方法参数校验需要在类上加 `@Validated`

## 📌 在 Spring Boot 中

- Spring Boot 自动配置了 `RequestMappingHandlerAdapter`，内置了所有参数解析器
- Jackson 自动配置：`ObjectMapper` 处理 JSON 序列化/反序列化
- Spring Boot 2.3+ 添加了 `spring-boot-starter-validation` 需要单独引入（之前是 Web Starter 自带的）
- `server.servlet.encoding.charset=UTF-8` 确保中文参数不乱码

## 本章小结

| 知识点 | 要点 |
| :--- | :--- |
| 请求映射 | `@GetMapping`/`@PostMapping`/`@PutMapping`/`@DeleteMapping` + `@RequestMapping` |
| @RequestParam | URL 查询参数 / 表单，支持 defaultValue、required、List |
| @PathVariable | URL 路径变量 `/users/{id}` |
| @RequestBody | JSON 请求体，Jackson 自动反序列化 |
| 参数校验 | `@Valid` + `@NotNull`/`@NotBlank`/`@Size`/`@Email` 等 |
| 统一返回 | `Result<T>` 包装 code + message + data |

---

## 学习建议

1. **每个参数绑定注解都亲手用一遍**：写一个 Controller，分别用 `@RequestParam`、`@PathVariable`、`@RequestBody`、`@RequestHeader` 接收参数，Postman 测试看效果。
2. **把校验注解配齐**：CreateUserRequest 的每个字段都加上合适的校验注解，发送各种不合法请求，观察 `MethodArgumentNotValidException` 的报错信息。
3. **统一返回格式是团队标配**：如果项目还没有统一的 `Result<T>` 响应体，建议引入。别让前端看 `{"code":200}` 和 `{"code":500}` 猜——定义好响应规范是一开始就该做的事。
